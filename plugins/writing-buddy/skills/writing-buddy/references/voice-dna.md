# Voice DNA

> **Status: Blank placeholder**
>
> This file will be populated during a personalization session. Until then, the authenticity reviewer operates in human authenticity mode — evaluating writing for genuine human tone, grounded specificity, and clear point of view rather than matching against a defined voice profile.

---

## How This File Will Be Used

Once populated, this file will define:

- **Identity statement** — Who is writing and why their perspective is worth reading
- **Core voice rules** — The 8–12 rules that define how this writer sounds
- **Sentence mechanics** — Rhythm patterns, emphasis tools, transition vocabulary
- **Paragraph construction** — Preferred shapes and densities
- **Things this voice never does** — The negative space that defines the style

## How to Populate This File

Run a personalization session where you share:
1. 2–3 pieces of writing you're proud of (any format)
2. Writing you admire from others and why
3. Topics you write about most
4. The audience you write for

From that session, the voice-dna.md will be drafted, reviewed, and locked in as the calibration target for all future writing.

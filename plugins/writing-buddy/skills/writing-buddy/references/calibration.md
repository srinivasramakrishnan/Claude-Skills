# Calibration Sentences

> **Status: Blank placeholder**
>
> This file will be populated during a personalization session with annotated excerpts from real published writing. These sentences become the gold standard — the test is whether new writing could sit alongside them without anyone noticing the join.

---

## How This File Will Be Used

During the critique phase, the authenticity reviewer will:
1. Read each calibration sentence to internalize the voice
2. For each paragraph in the draft, ask: "Could this appear in the same piece as the calibration sentences?"
3. Flag paragraphs where the answer is no

Each entry will include the verbatim sentence and an annotation explaining what makes it work — which patterns, rhythms, and choices create the effect.

## How to Populate This File

Provide writing samples during the personalization session. From those samples, 10–20 sentences will be selected that best represent the voice at its sharpest, most characteristic moments.
